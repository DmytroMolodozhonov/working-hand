## Наглость игрока и толпа жителей (просьба автора)
Автор: «В поселениях жители, если быть сильно наглым — грабить и убивать, — должны атаковать совместно (всей толпой), а те, кто боится, — убегать из деревни».
- **Файлы:** `src/game/Audacity.js` (чистые правила, числа `AUD`/`MOB`/`EXODUS`, очки `DEEDS`, таблица «кто что делает» `ROLE_MOB`, `NO_REASON`), `src/game/AudacityLife.js` (игровая часть, `life.aud`, хост), тест `tests/unit/audacity.test.js`. Нож кухонный — инструмент `knife` в `VillagerModel` (`TOOLS`, `toolBoxes`).
- **Наглость** — скрытое число 0…100 на пару «поселение × игрок» (не сохраняется, не показывается; журнал «решение:»). Растёт ТОЛЬКО от поступков, которые видели и узнали игрока (Blame.js: `_offence`/`theft`/`reportCrime`/`damaged` зовут `aud.deed(..., witnesses)`; нет свидетеля — нет очков): удар 6 (одного случайного удара мало; каждая следующая жертва за 2 мин весит больше — «нападение на нескольких»), убийство 35, грабёж 25, поджог 28, разрушение 0,5 за блок (≤ 25). Спадает через 30 с без поступков по 0,25/с, только пока место проснулось. Фазы с гистерезисом: косятся 18 → боятся 35 (слабые уходят из деревни, звонит колокол — `BuildingFx.alarm`) → толпа 60 (держится до 38). Убийство + грабёж = толпа; одно убийство — только страх.
- **Не касается** (`NO_REASON`): хозяин места (король — там `Rebellion.js`), друг короля (`Ranks.isForgiven`), дуэльный режим/арена (`ArenaDuels.peace()` — толпа сразу распускается), поступок без свидетелей, башни/города волшебников/хутора магов (`isWizSite`: у них свои правила), спящие, на приказе, в Левиосе, в сделке/разговоре (`talking`, `giveT` — сделка не рвётся), король/визирь/волшебники. Гость в мультиплеере — те же правила (хост ведёт).
- **Толпа:** кто дерётся (`fightsInMob`): мужчины-фермеры/строители с храбростью ≥ 0,25–0,3 (по семени человека, как `VillagerFear.brave`), торговцы покрепче (≥ 0,55), не у прилавка с товаром; НЕ дерутся: женщины, дети, старики, слабые, раненые (< 60 % hp), священник, торговец у товара. Рыцари — по старым правилам (идут на игрока сами и становятся «ориентиром» толпы: `pickLeader`). Оружие по месту работы (`weaponFor`): вилы/мотыга (фермер), молот (строитель, кузнец), кухонный нож (пекарь, трактирщик, травник, мельник, торговец), кулаки; код оружия — биты `fx` (`withTool`/`toolOf`, гости видят). Толпа ≤ `MOB.MAX` 14. Сбор → атака вместе: все идут на места дугой на стороне лидера в 11 м от игрока (`musterSpot`, разведены на 2,4 м), и бьют все РАЗОМ (`goNow`: пришло 60 %, или 7 с, или игрок подошёл на 8 м); в бою — `CastleLife._assignSlots/_fight` со стилем `MOB.STYLE` (до пяти одновременно со всех сторон, а не по трое с одной), ходьба — только `_steer` (Pilot). Урон вилами/молотом/ножом 2, кулаком 1.
- **Бегущие — теперь ДОМОЙ** (слова автора: «слабые бегут В СВОЙ ДОМ; из деревни — только если дом недоступен/разрушен»; `Audacity.shelters/leavesVillage(p, home)`, `VillagerFear.sendHome` — личная опасность только для этого человека, `HomeDefence.hasHome`): слабые (`shelters`) в фазе «боятся» бегут в свой дом по путям места и запираются (раздел «Страх → дом → оборона» ниже); из деревни по старым правилам (`refugeSpot`, ждут, `mayReturn`, `_leave`) уходят, только если дома нет / он сгорел / обвалился / дальше `OWN_REACH`. Бойцы «толпы» по-прежнему собираются; колокол звонит как раньше. Журнал: `прячется дома: наглость N…`, а «бежит из деревни: …» — лишь когда дома нет.
- **Журнал** («Жители»): `наглость «место» игрок: A → B (причина, свидетелей N) — фаза`, `набат`, `бежит из деревни: <старик/женщина/…>; наглость N`, `в толпе против игрока: роль, храбрость, берёт <оружие>`, `толпа … нападает вместе: N человек`, `толпа разошлась: <почему>`, `возвращается в деревню: …`.
- Новое человекоподобное существо в поселении — строка в `ROLE_MOB`; новый поступок — строка в `DEEDS` и вызов `aud.deed(...)` там, где он судится. Замер: `node tools/crowdbench.mjs --check` (ходьба не хуже).
