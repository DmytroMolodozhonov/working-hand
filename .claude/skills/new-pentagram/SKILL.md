# Новая пентаграмма — чек-лист

1. **Имя:** одно уникальное английское слово после «Pentagranium» — `src/game/PentagramWords.js` (`PENT_NAMES`); без путаницы по звучанию с другими. Тест `pentagram-words`.
2. **Рисунок:** свой уникальный (фигура, не цвет) по 16 точкам кольца — `PentagramFigures.js`; ни один рисунок не лежит целиком в другом при любом повороте. Классическая звезда — только дьявольская сила. Тест `pentagram-figures`.
3. **Реестр:** `Pentagrams.js` (`dark: false` — белая, `dark: true` — чёрная; чёрная магия — только если автор сказал; `use`: функция или `'система.метод'`), цена в `PentagramRules.js` (`CAST_COST`), `PENTAGRAM_TARGETS` («кто/что»).
4. **Каст:** палочка на землю → «Pentagranium <Name>» → мана снимается при слове → фигура рисуется сама (анимация); эффект при входе/ритуале — как у соседних (`PentagramUse.js`, `Pentagranium.js`); может отказать с причиной (`USE_WHY`).
5. **Знание:** только со свитка пентаграммы (`stat: 'pentagram'`, `pent: id`; `Pentagranium.learnFigure`; смерть забирает; «Give Me My Power» возвращает; `captureLegacy/wipeHero/absorbLegacy`). Источники свитков (`SCROLL_WEIGHTS`, `TAUGHT_BY`). Сохранение метки (`pentMarks`) и сеть (`pgm`).
6. **Вид и звук:** `PentagramFx.js`, звук заранее, один общий свет.
7. **Справочник:** «Магия → Пентаграммы» — карточка с рисунком: «Чтобы создать, направьте палочку на землю и скажите: Pentagranium <Name>…» (польза → как пользоваться, на «вы»).
8. **Тесты:** `pentagram-effects.test.js` (каждое имя даёт свой эффект), `pentagram-use`, свои. «А если»: нет маны, нет земли, не выучил, сеть, смерть, выход из круга.
