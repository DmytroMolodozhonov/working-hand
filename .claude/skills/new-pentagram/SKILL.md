# Новая пентаграмма — чек-лист

0. **Воспользуйся скиллом `optimization`** — код сразу под видеокарту и без просадок FPS.
1. **Имя:** одно уникальное английское слово после «Pentagranium» — `src/game/PentagramWords.js` (`PENT_NAMES`); без путаницы по звучанию с другими. Тест `pentagram-words`.
2. **Рисунок:** свой уникальный (фигура, не цвет) по 16 точкам кольца — `PentagramFigures.js`; ни один рисунок не лежит целиком в другом при любом повороте. Классическая звезда — только дьявольская сила. Тест `pentagram-figures`.
3. **Реестр:** `Pentagrams.js` (`dark: false` — белая, `dark: true` — чёрная; чёрная магия — только если автор сказал; `use`: функция или `'система.метод'`), цена в `PentagramRules.js` (`CAST_COST`), `PENTAGRAM_TARGETS` («кто/что»).
4. **Каст:** палочка на землю → «Pentagranium <Name>» → мана снимается при слове → фигура рисуется сама (анимация); эффект при входе/ритуале — как у соседних (`PentagramUse.js`, `Pentagranium.js`); может отказать с причиной (`USE_WHY`).
5. **Знание:** только с круглой таблички пентаграммы (`stat: 'pentagram'`, `pent: id`; `Pentagranium.learnFigure`; смерть забирает; «Give Me My Power» возвращает; `captureLegacy/wipeHero/absorbLegacy`). Источники обоих видов знаний (`SCROLL_WEIGHTS`, `TAUGHT_BY`) равноправны. Внутренний тип scroll/pentagram не менять; модель и рисунок автоматически делает `PentagramTablet.js`. Сохранение метки (`pentMarks`) и сеть (`pgm`).
6. **Вид и звук:** `PentagramFx.js`, звук заранее, один общий свет.
7. **Справочник:** «Магия → Пентаграммы» — карточка с рисунком: «Чтобы создать, направьте палочку на землю и скажите: Pentagranium <Name>…» (польза → как пользоваться, на «вы»).
8. **Тесты:** `pentagram-effects.test.js` (каждое имя даёт свой эффект), `pentagram-use`, свои. «А если»: нет маны, нет земли, не выучил, сеть, смерть, выход из круга.

- Если обряду нужны вещи/тела на круге — `PentagramOfferings.js` (`OFFERINGS`, `humanoidBody`; любое тело — `any: true` → `HellRules.anyBody`, туши зверей тоже идут) + `Offerings.js` (мана при слове, если в `OFFERINGS` `mana: 0`); переход куда-то — образец `HellGate.js` (`heroApply.pending` ждёт землю); если дар навсегда — образец `Firmitas.js`/`SecondSight.js` (флаг героя в сохранение, `captureLegacy/wipeHero/absorbLegacy`).

- Обряд с вещами в круге: мечи и топоры — НЕ `Items.loose`, а `Weapon` системы оружия (`g.weapons.weapons`); образец — `UnitedPower._contents`/`weaponThing` (`w.ritual` держит физику и запрещает хват), результат-оружие — `weapons.spawn` + `sync.weaponAppeared`.

## Если чего-то не хватило
Нашёл новое место в коде или ошибку, которую пришлось ловить, — допиши строкой в нужный пункт и закоммить вместе с работой. Правила — сначала в CLAUDE.md, потом сюда; не дублируй его, устаревшее удаляй.

- Создание ЛЮБОГО рисунка стоит 50 маны (`PENT.COST` / `CAST_COST`), отдельно от платы за использование. `mark.prepaid` относится только к оплаченному обряду: не выставлять его за оплату рисунка, иначе монстр/слом защиты пропускают свой обряд.
- Новое короткое имя может ошибочно победить на недосказанном старом имени: помимо `pentagram-words` прогнать `pentagram-lone` (синтетические буквы через настоящий `NativeVoice.lookAt`) и `npm run test:voice`. Пороги не ослаблять — выбрать различимое имя.

- Обряд NPC требует настоящего свидетеля и идёт во времени (`SoulSeal`): освобождать занятую цель при смерти/выгрузке исполнителя, сохранять метку отдельно от рисунка, не уничтожать останки, если обряд этого не требует. Сетевой возврат силы и запрещающий его обряд решает хост последовательно (`LegacyClaim`), не по запоздавшей локальной копии гостя.
