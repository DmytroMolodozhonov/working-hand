# Снимки из игры — `tools/shot.mjs`

Не писать новый `tools/*-screenshots.mjs` с нуля (их уже ~60, каждый заново запускал игру и камеру). Сцена — файл
`tools/shots/<имя>.mjs` с `export default async function (h, args) { … }`; она выполняется В СТРАНИЦЕ игры.

```
node tools/shot.mjs <имя> [--out папка] [--w 1280 --h 720] [--args '{"k":1}'] [--slow] [--mode creative]
```
- Снимки → `docs/media/shots/<имя>/*.png` (или куда скажет `h.shot(имя, {to: 'assets/bosses/x.png'})`).
- `ZNS_SHOT_DEBUG=1` печатает текущие этапы загрузки каждые 15 с; при сбое сохраняется `failure.png` и выводятся ошибки страницы. Быстрый режим пропускает синтез звуков и прогрев всех иконок; материалы снимаемой сцены компилируются настоящим рендерером.
- По умолчанию быстрый запуск: шейдеры собираются по мере появления в кадре (`window.__ZNS_SHOT_FAST__`, в игре этого нет) — в
  контейнере без видеокарты это экономит ~10 минут. `--slow` — полный прогрев, как у игрока.
- Запускать в фоне (`run_in_background`), лимит инструмента 40 мин, браузер и сервер закрываются сами (правило автора про стенды).
- Образец: `tools/shots/vampire.mjs`.

## Помощники `h`
- `h.g` (игра), `h.THREE`, `h.frames(n)`, `h.until(fn, ms)`, `h.log(...)` — печать в консоль инструмента.
- `h.go(x, y, z, fly = true)` — герой туда, ждёт землю воркеров, висит в воздухе.
- `h.time(0.3)` — время суток (0 рассвет, 0.3 день, 0.62 вечер, 0.8 ночь).
- `h.hold(list)` — существа стоят смирно. `h.bare()` — скрыть интерфейс и подписи.
- `h.cam([x,y,z], [x,y,z])` — камера там, смотрит туда. `h.view(obj, {d, up, at, side, face})` — камера сама находит место,
  откуда видно лицо obj и ничего не загораживает, и следует за ним.
- `await h.shot('имя', {settle: 20, light: 0, to})` — снимок сейчас.
