# voicebench — голос против Дискорда

Стенд, чтобы Дискорд (друг говорит через колонки) не мешал заклинаниям. Голоса синтетические (Piper), комната
имитируется (задержка, отражения, хвост, искажения колонок), всё идёт через настоящий `voice_native.offline()`,
а решения оценивает настоящий код игры (`lookAt`, `spellPhrase`, `soundTrust`).

    pip install numpy onnxruntime livekit sherpa-onnx piper-tts
    ZNS_VOICE_MODELS=/путь/к/моделям ZNS_BENCH_VOICES=/путь/к/голосам tools/voicebench/run.sh /tmp/vb --n 20
    node tools/voicebench/eval.mjs --why /tmp/vb/overlap.json     # почему пропущено каждое заклинание
    node tools/voicebench/eval.mjs /tmp/vb --check                # пороги из floor.json (только повышать)

Сцены: `clean` (тишина — эталон), `chat` (друг говорит, заклинания между его фразами), `overlap` (кричим поверх друга),
`loud` (громкие колонки, большая комната — самый тяжёлый случай), `ship` (никого нет, но колонки играют море: ветер, волны, скрип, выстрелы пушек — бой на корабле; порог в `floor.json` ставится после первого замера на вашей машине), `friendspell` (друг сам произносит заклинания — ни одно не
должно сработать). Колонки «узнано / лишних / задержка» — как в игре.

Что уже сделано (измерено): задержка с Дискордом 1000–1300 мс → 300–450 мс (как в тишине: 250); «overlap» 2 → 12 из 20;
«chat» 3 → 11 из 12; ложных срабатываний от речи друга нет.
