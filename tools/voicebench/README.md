# voicebench — голос против Дискорда

Стенд, чтобы Дискорд (друг говорит через колонки) не мешал заклинаниям. Голоса синтетические (Piper), комната
имитируется (задержка, отражения, хвост, искажения колонок), всё идёт через настоящий `voice_native.offline()`,
а решения оценивает настоящий код игры (`lookAt`, `spellPhrase`, `soundTrust`).

    pip install numpy onnxruntime livekit sherpa-onnx piper-tts
    ZNS_VOICE_MODELS=/путь/к/моделям ZNS_BENCH_VOICES=/путь/к/голосам tools/voicebench/run.sh /tmp/vb --n 20
    node tools/voicebench/eval.mjs --why /tmp/vb/overlap.json     # почему пропущено каждое заклинание
    node tools/voicebench/eval.mjs /tmp/vb --check                # пороги из floor.json (только повышать)

Сцены: `clean` (тишина — эталон), `chat` (друг говорит, заклинания между его фразами), `overlap` (кричим поверх друга),
`loud` (громкие колонки, большая комната — самый тяжёлый случай), `ship` (никого нет, но колонки играют море: ветер, волны, скрип, выстрелы пушек — бой на корабле; порог в `floor.json` ставится после первого замера на вашей машине), `friendspell` (друг сам произносит заклинания — ни одно не
должно сработать), `duel` (дуэль: друг отвечает ТЕМ ЖЕ заклинанием за 1 с до или после моего — его эхо не должно сработать,
моё не должно отсеяться как «эхо»; порога в floor.json пока нет — поставить после первого замера). Колонки «узнано / лишних / задержка» — как в игре.

Что уже сделано (измерено): задержка с Дискордом 1000–1300 мс → 300–450 мс (как в тишине: 250); «overlap» 2 → 12 из 20;
«chat» 3 → 11 из 12; ложных срабатываний от речи друга нет.

## echobench — голос друга из колонок (голосовой чат игры, Discord) против моих заклинаний

    ZNS_VOICE_MODELS=… ZNS_BENCH_VOICES=… python tools/voicebench/echobench.py --out /tmp/eb [--loopback] [--seed 1]
    node tools/voicebench/echoeval.mjs /tmp/eb [--check] [--why ingamespell]

Сцены: `ingame` (друг говорит через голосовой чат игры, я колдую между и поверх его фраз), `ingamespell` (друг произносит
заклинания, я молчу — ни одно не должно сработать), `discord` / `discordspell` (то же через Discord: +100–400 мс задержки,
копия голоса друга приходит по сети игры со сдвигом часов и дрожанием), `noise` (вентилятор, клавиши, музыка игры), `delay`
(эхо 40–300 мс, большая комната), `doubletalk` (кричу прямо поверх него). Без `--loopback` у нейросети нет копии колонок
(Mac, браузер) — самый тяжёлый случай; с ним — копия есть (Windows, или голосовой чат игры: игра сама отдаёт голоса друзей
нейросети, `/api/voice/ref`). Защита — `src/audio/EchoGuard.js`; пороги — `echofloor.json` (только ужесточать).

Измерено (seed 1, 16 заклинаний на сцену): без копии колонок ложных заклинаний от голоса друга 102 → 0, мои узнаны как
и без защиты (13), ни одно моё не отсеяно; с копией (Windows / голосовой чат игры) узнано 32 моих из 64 против 13 без неё,
ложных 0.
